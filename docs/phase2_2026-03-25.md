## Strategic Goal: Balanced Classification Dataset

Build a classifier that distinguishes:
- **Label 1 (Safe/Positive)**: Sequences that work in the lab
- **Label 0 (Unsafe/Negative)**: Sequences that fail despite model predictions

### Data Architecture

| Category | Source | Filter | Label |
|----------|--------|--------|-------|
| **Wild-types (Anchor)** | ProteinGym target_seq | Unmutated reference | 1 |
| **High-fitness Mutants (Nuance)** | ProteinGym DMS | DMS_score > 1.0 | 1 |
| **Hard Failures (Target)** | Phase 1 output | DMS_score < -1.0 | 0 |

## Task Details

### Task 2.1: Wild-type Extraction

**Source**: ProteinGym `reference_files/DMS_substitutions.csv`
**Column**: `target_seq` (unmutated reference sequence)
**Output**: `data/processed/wildtype_positives.csv`

### Task 2.2: High-fitness Mutant Extraction

**Source**: ProteinGym DMS assays
**Filter**: `DMS_score > 1.0` (significant fitness gain)
**Output**: `data/processed/highfitness_positives.csv`

### Task 2.3: Dataset Merge & Balance

**Strategy**:
- Combine positives (wild-type + high-fitness)
- Balance with negatives (hard failures)
- Target ratio: ~1:1 or slight negative skew

**Output**:
- `data/deathnote_data/train_balanced.csv`
- `data/deathnote_data/test_balanced.csv`
