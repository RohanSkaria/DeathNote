## Strategic Goal: Targeting the "Hallucination Gap"

The core objective is to identify **High-Confidence Hallucinations** - protein designs where models like AlphaFold predict high stability (high pLDDT scores), yet the proteins fail to function, express, or remain soluble in laboratory settings.

This phase shifts intelligence away from human diagnostic data (ClinVar) toward biophysical failure modes that plague synthetic proteins like **pdLLT**.

---

## Data Sources

| Source | Purpose | Target Data |
|--------|---------|-------------|

| **eSOL** | E. coli expression yields | Proteins with Yield < 5.0 uM |
| **WALTZ-DB** | Amyloid aggregation propensity | Stealth toxicity sequences |

## Task Details

### Task 1.1: ProteinGym Hard Negative Extraction (COMPLETED)

**Input**: 217 DMS CSVs in `/DeathNote/archive-data/DMS_ProteinGym_substitutions/`

**Filter Criteria**:
- `DMS_score < -1.0` (significant fitness drop = hard negative)
- Sequence length: 50-1024 AA
- No ambiguous residues (X, B, Z, J, U, O)

**Output**: `data/processed/proteingym_hard_negatives.csv` (559,735 rows)

**Columns**:
- `sequence_id`: Unique identifier (e.g., `A0A192B1T2_9HIV1_Haddox_2018_A30Q`)
- `full_sequence`: Complete amino acid sequence
- `dms_score`: Original fitness score (range: -87.0 to -1.0)
- `source`: "proteingym"
- `failure_type`: "fitness_drop"
- `label`: 0 (negative/unsafe)

---

### Task 1.2: eSOL Database Integration (COMPLETED)

**Source**: https://www.tanpaku.org/tp-esol/

**Method**: Download TSV + UniProt sequence fetch

**Filter Criteria**:
- `Yield < 5.0 uM` (expression failure)
- Sequence length: 50-1024 AA
- No ambiguous residues

**Output**: `data/processed/esol_low_yield.csv` (3,094 rows)

**Columns**:
- `sequence_id`: e.g., `ESOL_JW0002_thrB`
- `full_sequence`: Complete amino acid sequence
- `yield_um`: Expression yield in micromolar
- `solubility`: Solubility percentage
- `source`: "esol"
- `failure_type`: "low_expression"
- `label`: 0 (negative/unsafe)
